## 需求与范围

先用自己的话回答，不确定时说明原因。无需写 RTL、TB 或算法代码，可画图或给简短公式。先回答 FPGA 或 DSP 部分均可；开始任务前不用预读含实现细节的教程。

### FPGA 部分

1. 时序 always 块中阻塞与非阻塞赋值分别可能造成什么行为？如何避免组合锁存器？举自己理解的例子。
2. 一个模块输入每拍有效、内部处理延迟为 4 拍，它能否每拍接收新输入？说明延迟、启动间隔和吞吐量的区别。
3. ready/valid 接口遇到下游停顿时，上游的数据和控制信号需要满足哪些条件？复位时如何处理已经进入模块的数据？
4. 同步 RAM 的读延迟会怎样影响数据与 valid 的对齐？FIFO 满/空边界需要验证哪些情形？
5. 两个异步时钟域之间分别传单比特状态、脉冲和多比特数据时，你会关注哪些问题？哪些处理方式不能直接推广？
6. 仿真正常但实现后负时序裕量：你先看哪些报告、路径和约束？50 MHz 板载时钟是否足以确定所有 IO 时序约束？

### DSP 部分

7. 采样后频谱出现混叠时，如何区分采样条件、模拟输入和算法显示造成的问题？指出需要哪些信息。
8. FIR 的时域卷积和频域响应如何联系？有限长度 FFT 的频率分辨率、泄漏和零填充分别如何理解？
9. 有符号定点数需要记录哪些数值格式信息？加法、乘法和累加如何影响位宽、溢出与误差？
10. 一个 DSP 算法从浮点模型搬到 FPGA 后出现差异，你如何建立逐级证据链？给出需要对齐的输入、数值规则、延迟与结果。
