## 需求与约束

用户选择 MATLAB 或 Python，自行编写模型，不使用 HDL Coder 或生成 HDL。本任务分浮点和定点两步，可暂停在任一步。工具运行由用户实际执行并记录；MATLAB 许可或工具箱受阻可选择已验证 Python 入口，不将环境错误算作知识不足。

### 浮点部分

输入采样率 $F_s=8000\,\mathrm{Hz}$，长度 $N=1024$；样本索引 $n=0,\ldots,N-1$。测试信号规定为：

$$
x[n]=0.25\sin(2\pi\cdot500n/F_s)+0.25\sin(2\pi\cdot2500n/F_s).
$$

FIR 系数按 $h[0],h[1],h[2]$ 顺序为 $[0.25,0.5,0.25]$。输入前状态全为零；输出保留前 N 点因果结果，尾部补零冲洗如另做测试需单独标明，不与主结果混淆。

用户独立实现逐样本模型；可用语言自带卷积或滤波函数作为另一条对照路径，但不能只调用库函数替代独立模型。要求自行解释参考响应、启动瞬态、频率轴和幅度归一化。给出原信号/输出的时域及频域结果，不预先提供正确曲线或数值答案。

### 定点部分

沿用同一输入及 FIR。输入表示使用有符号 16 位整数、15 位小数；系数使用有符号 16 位整数、14 位小数；最终输出为有符号 16 位整数、15 位小数。

- 输入与系数量化采用最近值舍入，中点取偶数，再饱和到目标有符号范围。
- 乘积和内部累加位宽由用户推导并选择，说明小数位数、每一步是否截位及避免内部溢出的依据。最终输出转换采用相同的舍入与饱和规则。
- 用整数运算或明确的位精确方式模拟；不能只量化浮点输出就称为定点运算模型。负数、极值与饱和另设用户自拟测试。
- 对照包括原浮点参考与使用已量化输入/系数的浮点参考，区分输入/系数量化误差和运算/输出量化误差。
- 自行给出最大绝对误差、RMS 误差、饱和次数和至少一段逐样本比较；解释所用误差口径及零误差时的处理。无需强行给有限 SNR 数字。
