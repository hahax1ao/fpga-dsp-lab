## 需求与约束

用户独立使用 Vivado 2020.2 建立面向 `xc7z020clg400-2` 的分析工程，复用已验证 RTL；本项分析 50 MHz 单时钟设计的综合、布局布线、时序和资源。先由用户实际启动确认工具版本与许可证；失败保留错误，不用安装目录替代运行证据。

这是非上板的时序分析任务：不为算术数据接口任意分配板级引脚，不生成/下载 bitstream。用户说明采用的虚拟外部接口或其他非上板约束建模方式，并区分练习假设与真实板级条件。50 MHz 来源可参考厂家文件，但不要求把分析工程时钟端口绑定到 U18。

- 时钟及周期、外部输入输出时序假设由用户明确记录；不能假定任意 delay 就是真实外设要求。
- 分析寄存器到寄存器及外部接口路径覆盖情况；无实际协议时将板级 IO 时序验收标不适用，不能声称真实 IO 收敛。
- 不通过无依据的 false path、多周期约束或关闭检查掩盖问题。例外需解释需求依据。
- 复位假设、工具警告、未约束路径、setup/hold、时钟交互或 CDC 报告均需说明；单时钟结果不能证明具备完整 CDC 设计能力。
