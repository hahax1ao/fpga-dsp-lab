# 能力画像与证据

更新日期：2026-10-12。用户自述已有 FPGA 项目和竞赛经验；本仓库尚未诊断，不据此直接评级。所有领域目前为“未评估”，不等于 L0。

## 等级含义

| 等级 | 能力含义 | 证据要求 |
|---|---|---|
| L0 | 诊断证据显示尚未建立基础理解或独立操作能力 | 实际诊断问题与不足记录；不能用缺少证据判 L0 |
| L1 | 理解主要概念，但独立应用仍有困难 | 解释记录、任务成果及提示依赖 |
| L2 | 能独立完成、验证并解释常规工程任务 | 独立成果、边界覆盖、复现证据 |
| L3 | 能处理复杂约束、分析权衡、定位问题并优化系统 | 多维工程证据、设计权衡及优化前后比较 |
